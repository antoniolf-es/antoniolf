## Antonio LF

El objetivo es migrar y mejorar una pagina web que es un portafolio de un desarrollador web con blog propio para potenciarlo y modernizarlo siendo un lugar para mostrar habilidades y ejemplos.

### Opciones:

- Tendra un frontend y un backend (intranet)

## Stack

- Vanilla PHP con sistema propio MVC
- Base de datos con Mariadb
- CSS con framework bootstrap
- Usar Jquery para eventos adicionales
- Archivo .env para contraseñas importantes de bbdd, apis, etc
